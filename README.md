## 📂 仓库目录规范
本项目严格按照《学生实训手册 V1.0》第 4.2 节建议目录搭建，各目录说明如下：
- `docs/`：目标和验收要求、系统架构与风险图
- `cad/`：STEP/STL 模型与装配图
- `hardware/`：BOM 表、接线图、规格说明、测试台架
- `firmware/`：ESP32 可复现代码与配置文件
- `tests/`：测试脚本与验收步骤
- `data/`：原始数据索引、单位、校验信息
- `reports/`：每周报告、实验记录与失败复盘
- `LICENSES/`：开源引用与许可证记录
